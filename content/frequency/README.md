# Häufigkeitsliste Spanisch

`es_top5000.txt` enthält die ersten 5000 Zeilen der Datei `es_50k.txt` aus dem Projekt
FrequencyWords von hermitdave (Stand der Liste 2018, Spanisch), geladen von
https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/es/es_50k.txt

Aufbau: pro Zeile ein Wort und seine Häufigkeit, absteigend sortiert. Die Zeilennummer ist der
Rang, den die Inhalte als `freqRank` verwenden.

Die Liste stammt aus Film- und Serienuntertiteln (OpenSubtitles) und ist daher nahe an gesprochener Sprache,
aber nicht auf Chile zugeschnitten.
